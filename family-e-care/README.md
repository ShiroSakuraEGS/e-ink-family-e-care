# Family E-Care — 遠端家庭關懷電子紙系統 Prototype 3.0 (4.2" 橫向黑紅白版)

本系統依據使用者核心規格全面升級為 **「4.2 吋黑紅白 (BWR) 三色橫向電子紙」**，並採用 **[UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.git)** 無障礙（Accessible & Ethical + E-Ink Paper）設計規範，實現**指定 N 條常態訊息輪播**與**智慧定時排程插播聯動狀態機**。

---

## 🌟 核心架構與設計亮點

### 1. 螢幕規格與工藝外觀
- **純三色黑紅白 (BWR E-Ink)**：紙白色底（`#FBF9F5`）、深層墨黑（`#111827`）、飽和緋紅（`#C62828`）。專注高對比度文字與服藥警示，不再受全彩成本與刷新負擔影響。
- **橫向相框顯示 (Landscape Orientation)**：
  - 電子紙面板橫向 400×300 (600×380 映射)，適合置於客廳電視櫃、茶几或床頭櫃。
  - 雙欄式高易讀性版面：
    - **左欄**：星期、日期、特大時鐘、醒目三色狀態印章（`🔴 服藥提醒` 或 `🔄 常態輪播 [2/3]`）。
    - **右欄**：大字主標題、長輩 24~30px 無障礙正文、子女親筆手寫筆跡（紅色墨水）與溫馨署名。
- **北歐實木/陶瓷外殼 ＋ 實體大按鍵**：
  - 右側配置大顆「⭕ 我看到了 / 收到」內凹實體鍵（含機械微動開關 Click 音效）。
  - 配備側邊換頁微動開關（▲ / ▼）與 3V 壓電蜂鳴音孔。

---

### 2. 廣播調度與狀態機 (Carousel vs. Schedule State Engine)

本版本精準實作使用者的排程調度核心邏輯：

1. **常態輪播 (指定 N 條訊息循環)**：
   - 使用者可於 App 端**勾選指定任意 N 條訊息**（如 3 則或 5 則）加入播放池。
   - 可自選輪播間隔（每 15/30/60 分鐘或長輩手動翻頁）。
2. **純常態輪播模式 (不啟動排程提醒)**：
   - 切換至此模式時，排程定時器靜音，長輩裝置專注依循環間隔播放指定 N 條日常問候，排程不打擾。
3. **智慧混合插播模式 (推薦)**：
   - **場景一（單次排程顯示後返回常態輪播）**：
     - 到達 09:00 時，高優先權排程插播（如「09:00 吃降血壓藥」），客廳裝置發出可愛蜂鳴音，綠色 LED 呼吸閃爍。
     - 長輩走近按下實體大按鈕「我看到了」確認後，系統回傳 ACK 至子女手機動態島，裝置**自動無縫平滑恢復為常態輪播**！
   - **場景二（排程與排程之間的空檔時間行為）**：
     - 若排定 09:00 一則訊息、10:00 一則訊息，中間空檔時間支援：
       - `選項 A：空檔進行常態輪播`（播放指定 N 條日常關懷語）。
       - `選項 B：空檔無訊息 / 靜止大時鐘`（安靜待機，不播放輪播）。

---

### 3. UI/UX Pro Max 無障礙體系
- **字體**：載入 Google Fonts `Atkinson Hyperlegible`（無障礙視力友善字體）與 `Noto Sans TC`。
- **按鍵觸控區域**：全面符合大於 44×44px 標準，具備 3px 焦點環（Focus Ring）。
- **DevTools 時間場景演繹列**：
  - 內建一鍵時間演繹按鈕：`[08:59 常態輪播]` ➔ `[09:00 排程插播 🔔]` ➔ `[09:30 空檔輪播 🔄]` ➔ `[10:00 排程插播 🔔]`，即時驗收狀態機動態切換！
