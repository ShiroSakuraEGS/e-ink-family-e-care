# Family e-Care — 遠端家庭關懷電子紙系統 Prototype

本專案是基於元太科技 (E Ink) 3.6 吋 Spectra 6 彩色電子紙所打造的**家庭長輩遠端關懷與互動系統原型 (Interactive Prototype)**。

---

## 核心功能特色

### 一、遠端操作 App (左側手機視圖)
1. **🔄 輪播訊息 (文字)**：
   - 遠端設定客廳常態輪播關懷語。
   - 支援新增、啟用與自訂播送頻率。
2. **⏰ 排程訊息 (文字與提醒)**：
   - 設定定時關懷任務（如：早晚服藥提醒、醫院門診預約、家人活動等）。
   - 支援一鍵推播與預約排程。
3. **🎨 圖像與 Emoji 設計器**：
   - 支援 Spectra 6 鮮明彩色配色（紅、黃、藍、綠、黑）。
   - 搭配可愛 Emoji 貼圖與祝福文字，專為 400×600 電子紙卡片排版。
4. **⚙️ 設定中心 (裝置綁定與 Wi-Fi)**：
   - 綁定客廳裝置識別碼（例：`EC-8823`）。
   - 家用 Wi-Fi SSID 與密碼遠端配網。
5. **📋 訊息資料庫 (狀態追蹤與稽核)**：
   - 即時追蹤長輩是否已在實體裝置上「**按下按鈕確認閱讀**」。
   - 清楚統計：總發送數、已按鈕確認數、等待長輩閱讀數。

---

### 二、e-Care 實體裝置模擬器 (右側擬真硬體視圖)
1. **⏱️ 每 5 分鐘自動輪詢**：
   - 具備即時倒數計時器（`04:59` ➔ `00:00`）。
   - 每 5 分鐘自動向雲端檢查是否有新訊息。
2. **🟢 綠色 LED 呼吸閃爍通知**：
   - 只要偵測到子女發送的新訊息，頂部綠色指示燈立即高亮**呼吸閃爍**，吸引長輩注意。
3. **🔊 可愛蜂鳴器提示音 (Web Audio API)**：
   - 偵測到新訊息時，自動合成播放一次清脆溫和的三重升調提示音（C5-E5-G5），免外掛音訊檔即可發聲。
4. **⭕ 長輩專用實體大按鈕**：
   - 長輩走近裝置按壓「**閱讀 / 更新螢幕**」實體按鈕後，才會啟動畫面更新。
5. **✨ 3.8 秒擬真電子紙顆粒刷新特效**：
   - 按下按鈕後，模擬 Spectra 6 黑白彩色顆粒動態翻轉，耗時精確為 **3.8 秒**。
   - 刷新完成後顯示最新訊息，綠色 LED 自動熄滅恢復待機，並在資料庫中將該訊息標記為「**✅ 已按鈕確認**」。

## 快速本機體驗

在 PowerShell 中切換到該目錄並啟動伺服器：

```powershell
cd "C:\Users\Anubis.Chan\Downloads\E ink\e-badge-platform\family-e-care"
python -m http.server 8080
```

開啟瀏覽器前往：`http://localhost:8080`

### 互動測試建議流程
1. 點擊頂部的 **「⚡ 模擬新訊息推播」** 按鈕（或切換至 App 的「圖像 Emoji」分頁發送卡片）。
2. 觀察右側實體裝置：**綠色 LED 開始閃爍**，並響起**一次可愛的蜂鳴提示聲**！
3. 查看手機 App 的「訊息庫」分頁，可看到該訊息顯示 **「⏳ 等待長輩閱讀」**。
4. 點擊裝置上的實體大按鈕 **「⭕ 閱讀 / 更新螢幕」**。
5. 觀賞 **3.8 秒** 的電子紙顆粒刷新動態，3.8 秒後畫面呈現最新關懷卡片，LED 熄滅。
6. 回到手機 App 的「訊息庫」分頁，狀態已自動刷新為 **「✅ 已按鈕確認」**！
