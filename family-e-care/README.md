# Family E-Care — 遠端家庭關懷電子紙系統 Prototype (BOM & 規格驗證版)

本專案是依據案主最新「**產品規格說明書**」與「**完整物料清單 (BOM)**」所建構的家庭長輩遠端關懷電子紙系統互動原型。

---

## 核心硬體與系統特色 (對應 BOM 規劃)

- **目標建議售價**：量產建議售價控制在 **NT$2,000 以內**。
- **低成本 MCU ＋ Wi-Fi 架構**：採用 STM32L4 / ESP32-C3 作為主控，透過家庭既有 Wi-Fi 實現遠端傳輸。
- **NFC 的正確認位**：**僅用於初次手機一碰配對與家用 Wi-Fi 快速配網 (Provisioning)**。
- **4–6 吋平面電子紙**：優先評估 4.01 吋全彩 (ACeP) 或 4.2 吋黑紅白三色，以靜態訊息閱讀為主，不採用昂貴觸控屏。
- **實體按鍵操作**：正面配置大顆 12×12mm 實體「**我看到了 / 收到**」確認按鈕，側邊配置微動換頁開關。
- **350mAh 可充電鋰聚合物電池**：Type-C 充電介面，搭配 Deep Sleep 深度睡眠與 RTC 定時喚醒，待機續航可達 35~45 天。
- **多重提醒機制**：未讀暖黃/雙色 LED 呼吸閃爍通知，搭配 3V 壓電蜂鳴器可愛升調提示音。

## 核心功能模組

### 一、遠端操作 App (左側手機視圖)
1. **🔄 輪播訊息**：遠端設定客廳常態輪播關懷語，支援 RTC 定時輪替。
2. **⏰ 排程提醒**：設定服藥提醒、醫院門診等定時關懷任務，支援預約排程。
3. **🎨 圖像與 Emoji 設計器**：提供電子紙專屬調色盤、Emoji 貼圖與卡片祝福排版。
4. **⚙️ 設備與配網**：模擬手機 NFC 一碰觸碰寫入家用 Wi-Fi SSID 與密碼。
5. **📋 訊息庫與閱讀確認**：即時追蹤長輩是否已按壓實體「**看到了**」按鈕回傳 ACK。

### 二、實體裝置模擬器 (右側擬真硬體視圖)
1. **⏱️ RTC 定時喚醒輪詢**：倒數計時器（每 5 分鐘短暫喚醒 Wi-Fi 查詢新訊息）。
2. **🟢 LED 呼吸閃爍通知**：偵測到新訊息時高亮呼吸閃爍。
3. **🔊 壓電蜂鳴提示音**：Web Audio API 原生合成可愛清脆升調音。
4. **⭕ 實體「看到了」大按鈕**：長輩按壓後才觸發更新，並回傳閱讀確認至雲端。
5. **◀ ▶ 側邊微動按鈕**：長輩可手動翻閱上一則 / 下一則歷史訊息。
6. **✨ 3.8 秒電子紙顆粒刷新**：動態展示電子紙顆粒物理翻轉過程，3.8 秒後呈現新畫面。

## 快速本機體驗

在 PowerShell 中切換到該目錄並啟動伺服器：

```powershell
cd "C:\Users\Anubis.Chan\Downloads\E ink\e-badge-platform\family-e-care"
python -m http.server 8080
```

開啟瀏覽器前往：`http://localhost:8080`

### 互動測試建議流程
1. 點擊頂部的 **「⚡ 模擬新訊息推播」** 按鈕（或切換至 App 的「圖像 Emoji」分頁發送卡片）。
2. 觀察右側實體裝置：**綠色 LED 開始閃爍**，並響起**一次可愛的蜂鳴提示聲**！
3. 查看手機 App 的「訊息庫」分頁，可看到該訊息顯示 **「⏳ 等待長輩閱讀」**。
4. 點擊裝置上的實體大按鈕 **「⭕ 閱讀 / 更新螢幕」**。
5. 觀賞 **3.8 秒** 的電子紙顆粒刷新動態，3.8 秒後畫面呈現最新關懷卡片，LED 熄滅。
6. 回到手機 App 的「訊息庫」分頁，狀態已自動刷新為 **「✅ 已按鈕確認」**！
