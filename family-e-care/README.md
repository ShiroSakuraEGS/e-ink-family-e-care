# Family E-Care — 遠端家庭關懷電子紙系統 Prototype

本專案專注於 **「手機端 Family E-Care App 設計」** 與 **「客廳 4–6 吋電子紙實體裝置擬真顯示」**，完全體現案主在產品規格說明書與 BOM 清單中的硬體選型思考。

---

## 一、 手機端 App 核心設計亮點 (左側手機視圖)

1. **🎨 關懷卡片視覺設計器 (即時 Canvas 渲染)**：
   - 搭載 **400×600 即時渲染畫布**，輸入文字、挑選 Emoji 即刻預覽。
   - 提供 4 種長輩生活主題版型快速切換：
     - 🌸 **溫馨問候版**：日常家庭問候與生活叮嚀。
     - 💊 **服藥提醒版**：醒目服藥項目與溫開水服用說明。
     - 📅 **節慶門診版**：台大醫院門診回診專車預約提醒。
     - 🖼️ **照片生活版**：支援上傳生活照，自動執行電子紙色彩抖動。
   - 專屬 Spectra 6 調色盤（紅、暖黃、綠、藍、黑）與長輩友善大字體排版。
2. **🔄 客廳常態輪播管理**：
   - 設定家庭常態輪播內容，支援自訂輪換頻率（30分 / 1小時 / 2小時）。
3. **⏰ 預約排程提醒**：
   - 服藥、門診、喝水、散步等生活分類標籤，到達設定時間自動觸發客廳裝置提醒。
4. **📋 訊息庫與閱讀確認 (ACK 狀態機)**：
   - 即時追蹤長輩是否已按壓實體「**我看到了**」按鈕，狀態自動從「⏳ 等待長輩閱讀」轉為「✅ 長輩已按鍵確認」。
5. **⚙️ 設備綁定與 NFC 一碰配網**：
   - 模擬手機 NFC 貼近裝置一碰寫入家用 Wi-Fi SSID 與密碼。
   - 即時展示 **350mAh 鋰電健康度（96%）** 與預估待機天數（38 天）。

## 二、 客廳實體裝置模擬器亮點 (右側擬真硬體視圖)

1. **🎨 全彩模式 vs 三色模式一鍵比對**：
   - 頂部支援切換 **4.01 吋全彩模式 (Spectra 6/ACeP)** 與 **4.2 吋黑紅白三色模式 (BWR)**，直觀評估面板色彩與 NT$2,000 目標售價之取捨。
2. **✨ 3.8 秒分階段電子紙顆粒物理刷新動畫**：
   - 依據真實電子紙驅動波形（Waveform），完整模擬 4 個刷新階段：
     - **階段 1 (0.0~0.8s)**：全黑清除 (Clear Black)
     - **階段 2 (0.8~1.6s)**：全白清除 (Clear White)
     - **階段 3 (1.6~2.8s)**：彩色顆粒物理震盪翻轉 (Inversion & Settling)
     - **階段 4 (2.8~3.8s)**：畫面靜態成型，伴隨微動開關與完成音。
3. **⭕ 12×12mm 實體「我看到了 / 收到」按鍵**：
   - 長輩走近按壓大按鈕，發出清脆的**微動開關機械 Click 音效**（Web Audio API），隨後啟動 3.8 秒刷新並向雲端回傳 ACK。
4. **◀ ▶ 側邊微動按鈕 (上則/下則)**：
   - 長輩可手動隨時翻閱過往的歷史關懷與排程。
5. **🟢 暖黃/綠色未讀指示 LED 呼吸燈 ＋ 3V 壓電蜂鳴音**：
   - 當遠端子女發送新訊息或到達排程時間時，LED 進入平滑呼吸閃爍，並發出可愛的三重升調提示音。
6. **低功耗狀態機**：
   - 平時處於 Deep Sleep（<15µA），每 5 分鐘由硬體 RTC 短暫喚醒查詢訊息。

## 三、 本機快速預覽方式

請於 PowerShell 執行：

```powershell
cd "C:\Users\Anubis.Chan\Downloads\E ink\e-badge-platform\family-e-care"
python -m http.server 8080
```

開啟瀏覽器前往：**`http://localhost:8080`**

### 推薦體驗流程：
1. 在 App「**關懷卡設計**」分頁修改文字、更換 Emoji 或切換版型，觀察上方 400×600 Canvas 畫布的即時渲染。
2. 點擊「**🚀 發送卡片至長輩客廳裝置**」或頂部的「**⚡ 子女手機發送關懷卡**」。
3. 觀察右側客廳機身：**LED 呼吸閃爍亮起**，並播放**可愛蜂鳴提示音**。
4. 點擊客廳機身正面的大紅按鈕 **「⭕ 我看到了 / 收到」**，聆聽**微動開關 Click 音效**，觀賞 **3.8 秒分階段電子紙刷新**。
5. 點擊頂部 **「⚪🔴 三色模式」** 按鈕，感受黑紅白三色面板的高對比視覺表現！
